🎤 Hakamlar hay’ati uchun 1 daqiqalik nutq (Pitch)

"Hurmatli hakamlar! Bizning ilovamiz shunchaki chiroyli interfeys emas, balki chekka hududlardagi past quvvatli smartfonlar va beqaror internet sharoitida uzluksiz ishlashga moslashtirilgan yuqori muhandislik yechimidir: 1) Kod sifati: 100% TypeScript va Clean Architecture asosida qurilgan, biznes mantiq va UI to‘liq ajratilgan; 2) Ishlash tezligi: Offline-First arxitekturasida barcha amallar 0 ms kechikishda darhol ishlaydi, sovuq yuklanish esa 1 soniya; 3) Resurs tejamkorligi: APK hajmi atigi 4.5 MB, 2 GB RAM li arzon telefonlarda ham qotmaydi, batareyani tejaydi va internet paydo bo‘lganda faqat o‘zgargan ma’lumotlarni (Delta-Sync) uzatadi."

1. Kod sifati va Arxitektura (Code Quality)

TypeScript Strict • Clean Architecture • Pure Functions

🧩 100% Type-Safety & Modullilik

Barcha subyektlar (bemor, ko‘rik, vital ko‘rsatkichlar, dori-darmonlar) qat’iy interfeyslar orqali tiplashtirilgan. Kodda any ishlatilmagan. tsc -b 0 ta xato bilan toza kompilyatsiya bo‘ladi.

  • UI Qatlami: Mustaqil, qayta ishlatiluvchi React komponentlari.
  • Xizmatlar Qatlami: StorageService va ApiService.

⚡ Deterministik Klinik Algoritmlar

Klinik qaror qabul qilish (Manchester Triage va Red Flag tahlili) Pure Functions (sof funksiyalar) sifatida alohida ajratilgan. Side-effectsiz ishlaydi va avtomatlashtirilgan testlarga 100% tayyor.

  • Fallback Tizimi: AI server uzilsa ham, lokal algoritm bemor xavfini to‘g‘ri baholaydi.

2. Ishlash tezligi va Unumdorlik (Performance & Latency)

Offline-First • Zero-Lag UI • Asynchronous ASGI

🚀 0 ms Kechikishli Offline-First

Qishloq joylarida internet bo‘lmaganda ham ilova to‘xtamaydi. Yangi qabul ochish, EKG/AQB yozish, dori qoldig‘idan ayirish va chek chiqarish darhol (0 ms) amalga oshadi.

  • Vite Bundler: HTML 0.6 KB, CSS 17 KB, JS 172 KB.
  • Yuklanish: Cold-start 1 soniya, 60 FPS silliq skroll.

🔍 In-Memory Indekslangan Qidiruv

O‘zbekistonning barcha 14 ta hududi, 208 ta tuman/shaharlari va dori zaxiralari bo‘yicha qidiruv xotirada mikrosekundlarda filtrlanadi. Harf terilganda qotish (lag) bo‘lmaydi.

  • FastAPI Backend: Async Event-Loop orqali yuzlab so‘rovlarni parallel qayta ishlaydi.

3. Resurslardan foydalanish samaradorligi (Resource Efficiency)

4.5 MB APK • Delta Sync • Batareya va RAM Tejamkor

📦 Ultra-Yengil APK: Atigi 4.5 MB

Oddiy React Native/Flutter ilovalari 45–90 MB hajmga ega. Bizning ilovamiz Capacitor Native Core tufayli bor-yo‘g‘i 4.5 MB joy oladi. Eski va arzon smartfonlarda ham tez o‘rnatiladi.

  • RAM Sarfi: O‘rtacha 40–65 MB operativ xotira (2 GB RAM telefonda ham yengil ishlaydi).

🌐 Tarmoq va Batareya Tejamkorligi

Cheksiz foniy so‘rovlar (polling) yo‘q. Faqat Event-Driven arxitektura. Klinik fotosuratlar mobilning o‘zida Canvas orqali avtomatik siqilib keyin jo‘natiladi.

  • Delta-Sync: Butun bazani emas, faqat o‘zgargan JSON qatorlarini yuboradi.
  • GPU Acceleration: Animatsiyalar CPU’ni qizdirmaydi.
